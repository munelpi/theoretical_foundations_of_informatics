## Задача
Консольная программа обрабатывает заявки сервисного центра: загружает записи из `input.txt`, проверяет их, распределяет по очередям, обслуживает и отменяет заявки, хранит историю и формирует отчёт.

## Формат входного файла
Одна заявка на строку, пять полей через точку с запятой:

`номер;клиент;тип;категория;приоритет`

Типы: `ремонт`, `консультация`, `установка`. Приоритеты: `обычная`, `срочная`.

## Запуск
Поместите `main.py`, `data_structures.py` и `input.txt` в одну папку. Выполните:

```bash
python main.py
```

## Структура программы
- `data_structures.py` — узел, связный список, стек, очередь и хэш-таблица.
- `main.py` — чтение и проверка файла, операции с заявками, статистика, меню, тесты и сохранение отчёта.
- `input.txt` — тестовые данные с корректными и ошибочными строками.
- `report.txt` — создаётся программой после выбора пункта 9.

## Реализованные структуры
- `LinkedList`: `append`, рекурсивный `find`, рекурсивный `to_list`, `reverse`.
- `Stack`: `push`, `pop`.
- `Queue`: `enqueue`, `dequeue`, `remove_value`.
- `HashTable`: `insert`, `get`.

## Ссылочная модель
Каждый узел хранит значение и ссылку `next`. Очередь хранит ссылки на голову и хвост, поэтому добавление в конец и удаление из начала выполняются за O(1). При удалении из середины очереди перенаправляется ссылка предыдущего узла. Присваивание связывает имена с одним объектом, а не создаёт копию.

## Примеры
Корректная запись: `2001;Иванов Иван;ремонт;компьютер;обычная`  
Некорректная запись: `2015;Павлов Кирилл;ремонт;компьютер` — неверное количество полей.

## Обрабатываемые ошибки
Отсутствующий файл, неверное число полей, неправильный номер, повтор номера, пустые обязательные поля, неизвестный тип и приоритет, пустые очередь/стек, отмена отсутствующей заявки, отсутствие результата поиска и неизвестный пункт меню.
